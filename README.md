# NAWA — برنامج DRG Landing Page

Landing page لبرنامج تصنيف المجموعات التشخيصية (DRGs) — نوا للتدريب الصحي.

## الملفات

```
nawa-drg/
├── index.html        ← الصفحة الرئيسية
├── DRG-LINKEDIN.jpg  ← صورة Hero
├── DRG-SM.jpg        ← صورة السوشيال ميديا
├── DRG-STORY.jpg     ← صورة الستوري
└── README.md
```

## الرفع على GitHub Pages

1. ارفعي الملفات على ريبو جديد
2. روحي **Settings → Pages**
3. اختاري `main` branch → `/root`
4. الموقع يطلع على: `https://yourusername.github.io/repo-name`
